# 에스크로 금고란? (CFO Agent)

> **에스크로 금고 = 창업자가 맡긴 돈을 "규칙대로만" 내보내는 스마트컨트랙트.**
> 설계 전체는 [`docs/designs/cfo-agent-escrow-topup.md`](designs/cfo-agent-escrow-topup.md)를 참고.

## 에스크로란

에스크로는 **돈을 중간에서 맡아 두었다가 조건이 맞을 때만 내보내는 장치**다. 일상에서 흔히 보는 예는 두 가지다.

- **중고거래 안전결제**: 구매자가 낸 돈을 플랫폼이 가지고 있다가, 물건을 받았다는 확인이 나면 판매자에게 넘긴다.
- **호텔 가승인**: 체크인 때 카드 한도를 먼저 잡아 두고, 체크아웃 때 실제로 쓴 만큼만 결제한다.

## 우리 설계의 "금고"

중간에서 돈을 맡는 쪽이 사람이나 회사가 아니다. Base Sepolia에 배포한 **컨트랙트 `AgentBudgetVault`**가 그 역할을 한다.

```
창업자 지갑 ──fund(100 USDC)──▶ [ 금고 컨트랙트 ] ──settle──▶ 허용된 벤더 A/B/C
                                  │ 예산 100
                                  │ 잡아 둔 돈(committed)
                                  │ 기한, STOP 여부
                                  │ 허용 벤더 목록, 호출당 상한(maxHold)
                                  │ 작업별 hold
                                  └─ 남은 돈 ──refund──▶ 창업자
```

| 함수 | 호출 주체 | 하는 일 |
|---|---|---|
| `fund` | 창업자 | 예산을 금고에 넣고 기한을 정한다 |
| `open` | 에이전트 | 작업 하나에 쓸 돈을 **먼저 잡아 둔다(hold)**. 예: 벤더 B에 $2.64 |
| `topUp` | 에이전트 | 그 작업의 hold를 **충전**한다. 코드 게이트와 CFO Qwen 심사를 모두 통과한 경우에만 |
| `settle` | 에이전트 / 창업자 | hold 안에서 **실제로 쓴 만큼만** 벤더에게 지급한다. 수수료 3%는 이때 뗀다 |
| `close` | 에이전트 / 창업자 | 작업을 끝내고, 쓰지 않은 hold를 풀어 준다 |
| `refund` | 창업자 | 어떤 작업에도 잡혀 있지 않은 돈을 돌려받는다 |

## 서버 지갑으로 바로 결제하지 않는 이유

규칙을 우리 서버가 아니라 **체인이 지키게** 하려는 것이다.

- **서버가 털려도 안전하다.** 우리 코드에 버그가 있거나 에이전트 키를 탈취당해도, 금고가 아래 요청을 막는다.
  - 허용 목록에 없는 주소로 보내기
  - 예산·호출당 상한(`maxHold`)·기한을 넘는 요청
  - STOP 상태에서의 지출
- **위반은 조용히 사라지지 않는다.** 규칙을 어긴 요청이 오면 금고는 돈을 움직이지 않는다. 대신 `Denied` 이벤트를 체인에 남긴다(revert하지 않는 방식).
- **누구나 검증할 수 있다.** 모든 입출금과 거절이 체인에 기록된다. 제3자는 우리 서버를 믿지 않고도 "허락된 범위 안에서만 썼는지"를 확인할 수 있다. Challenge B가 요구하는 것이 바로 이것이다.

## Akash와의 관계

탈중앙 GPU 마켓 Akash가 실제로 이 방식으로 결제한다. 배포할 때 에스크로 계정에 돈을 예치하고, GPU를 쓰는 동안 제공자가 사용분을 인출해 가고, 모자라면 더 예치하고, 끝나면 남은 돈을 돌려받는다. 우리는 이 규칙을 EVM 테스트넷 컨트랙트로 옮겼다.

| 우리 금고 | Akash |
|---|---|
| `fund` | AccountDeposit (예치) |
| `open` | CreateLease |
| `topUp` | AccountDeposit (충전) |
| `settle` | WithdrawLease |
| `close` | CloseLease |
| `refund` | CloseDeployment 후 남은 예치금 환불 |

## "충전식"은 금고를 쓰는 방법

- **에스크로 금고**는 돈을 담고 규칙을 강제하는 **그릇**이다.
- **충전식**은 그 그릇에서 **언제 얼마를 잡을지** 정하는 방식이다. 처음에는 작게 잡는다. 잔액이 hold의 40% 밑으로 떨어지면 충전을 요청하고, 심사를 통과하면 `topUp`한다.

교통카드로 치면 **금고는 카드사 계좌**이고, **충전식은 "잔액이 부족하면 승인받고 충전"하는 사용 방식**이다.
